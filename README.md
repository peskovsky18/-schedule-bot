# Schedule Bot — расписание РГПУ им. А. И. Герцена

Телеграм-бот, который показывает расписание занятий по данным
[guide.herzen.spb.ru](https://guide.herzen.spb.ru/schedule).

Кнопки: **📅 Сегодня**, **⏭ Завтра**, **📆 Неделя** (ближайшие 7 дней).
Для администратора доступна панель `/admin`: статистика, список
пользователей, рассылка и логи ошибок.

## Как это работает

Бот работает через **webhook**: Telegram отправляет POST-запрос на сервер
при каждом сообщении, сервер отвечает. Постоянный процесс и long polling
для продакшена не нужны — но для локальной отладки polling поддерживается.

Расписание берётся со страницы `.../schedule/<ID>/by-dates`. Данные
разбираются из JSON внутри Livewire-снимка (`wire:snapshot`), где уже есть
готовые поля: дата, время начала и конца, предмет, тип занятия,
преподаватель, аудитория, примечание и ссылка на курс в Moodle.
Если снимок недоступен, включается резервный разбор HTML.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `WEBHOOK_URL` | для webhook | Публичный адрес сервиса, например `https://my-bot.onrender.com`. Бот сам вызовет `setWebhook` при старте |
| `GROUP_ID` | нет | ID группы на сайте. По умолчанию `25111` (4об_ППРСД/23) |
| `GROUP_NAME` | нет | Название группы, например `4об_ППРСД`. Если задано, актуальный ID ищется автоматически |
| `ADMIN_ID` | нет | Telegram ID администратора. По умолчанию `439819918` |
| `TELEGRAM_SECRET` | нет | Секрет для проверки, что запросы действительно от Telegram |
| `USE_POLLING` | нет | `1` — работать через long polling вместо webhook |
| `PORT` | нет | Порт для локального запуска, по умолчанию `8080` |

### Про `GROUP_ID` и `GROUP_NAME`

ID группы на сайте выдаётся на учебный год и **меняется каждое 1 сентября** —
именно поэтому расписание когда-то перестало работать. Надёжнее задать
`GROUP_NAME`: бот найдёт актуальный ID сам. Посмотреть название и ID своей
группы можно на [странице расписания](https://guide.herzen.spb.ru/schedule).

Указывайте название полностью (`4об_ППРСД` или `4об_ППРСД/23`) — сравнение
регистронезависимое и суффикс года отбрасывается. Если задать только
фрагмент вроде `ППРСД`, бот возьмёт первую подходящую группу, а это может
оказаться чужое расписание.

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Через long polling — webhook и публичный адрес не нужны
export TOKEN="ваш_токен"
export USE_POLLING=1
python bot.py
```

Проверить состояние сервиса: `GET /health` возвращает количество дней и пар
в расписании.

## Развёртывание

### Netlify не подходит

Netlify Functions работает на TypeScript, JavaScript и Go —
[Python-рантайма там нет](https://github.com/netlify/context-and-tools/blob/main/skills/netlify-functions/SKILL.md).
Кроме того, Netlify — serverless: постоянного процесса нет, диска нет,
а вызов ограничен по времени. Для бота на Python нужен хостинг с
долгоживущим процессом.

### Что подойдёт

| Хостинг | Особенность |
|---|---|
| **Render** | бесплатный тариф, Python из коробки. Минус: сервис засыпает при простое ~15 минут, первый запрос после паузы идёт 30–60 с |
| **Railway** | не засыпает, но бесплатный лимит ограничен |
| **Fly.io** | Docker, постоянно включён, нужна карта |
| **VPS** | полный контроль, платно |

Команда запуска для Render:

```
gunicorn bot:app --bind 0.0.0.0:$PORT --workers 1 --threads 4
```

Достаточно одного воркера: webhook регистрируется при старте процесса.

Чтобы бесплатный сервис не засыпал, можно пинговать `/health` раз в
10–14 минут через cron-job.org или UptimeRobot.

## Ограничения

- **`users.json` не переживёт перезапуск** на бесплатном хостинге: диск там
  эфемерный. Список пользователей для рассылки будет обнуляться. Ошибка
  записи не ломает бота — `/start` продолжит работать. Для постоянного
  хранения нужно внешнее хранилище (Redis, Postgres или GitHub Gist).
- **Расписание кэшируется на 5 минут** (`CACHE_TTL` в `parser.py`).
- Разбор зависит от структуры сайта. Если вёрстка изменится, бот
  переключится на резервный разбор HTML, а в логах появится
  `[PARSE] JSON недоступен`.
